AmneziaWG Universal

Что это? VPN-клиент для телевизора LG на webOS 4.x с root-доступом. Предназначен для подключения к вашему собственному серверу AmneziaWG. Приложение не предоставляет VPN-сервис и не содержит готовых аккаунтов.

Что умеет

  • Подключается к своему VPS по конфигурации AmneziaWG в файле .conf.
  • Позволяет передать .conf с телефона или компьютера в одной домашней сети по временному адресу и восьмизначному коду.
  • Поддерживает VPN для IPv4 и режим, в котором российские IPv4-сети идут напрямую.
  • По желанию включает VPN при загрузке телевизора.
  • Может включать и выключать VPN при длительном нажатии жёлтой кнопки пульта. По умолчанию функция отключена.

Как начать

  1. Нужен телевизор LG webOS 4.x (ARMv7) с root и Homebrew Channel.
  2. Заранее настройте собственный сервер AmneziaWG и получите его файл .conf.
  3. Установите и откройте AmneziaWG Universal.
  4. Нажмите «Установить компоненты», затем импортируйте .conf.
  5. Выберите режим маршрутизации и включите VPN.

Как передать .conf с телефона: в приложении нажмите «Загрузить .conf с телефона». На экране появятся адрес и одноразовый код. Откройте этот адрес в браузере телефона в той же домашней сети, выберите файл и введите код. Приём открыт только 5 минут.

Важные ограничения

Тестовая версия 1.0.3. Проверялась на LG webOS 4.10 (ARMv7). Не гарантируется совместимость с другими моделями и всеми VPS. Поддерживается только IPv4: системный DNS не перенастраивается, возможны утечки DNS, отсутствует kill switch.

Безопасность: передача .conf через локальную страницу идёт по незашифрованному HTTP. Используйте её только в доверенной домашней сети; конфигурация содержит секретный ключ. Для более защищённой передачи используйте SSH/SFTP.

Все публичные установочные файлы находятся на GitHub. Приложение не подключается к личному серверу разработчика.

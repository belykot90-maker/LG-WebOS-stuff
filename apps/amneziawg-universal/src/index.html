1. Импорт профиля AmneziaWG

Рекомендуемый способ — загрузить файл с телефона или компьютера в домашней сети:

Временная локальная страница с восьмизначным кодом, работает только 5 минут. Передача по HTTP без шифрования — используйте доверенную домашнюю сеть.

Или вставьте содержимое файла .conf из вашего собственного VPN-сервера: [Interface], [Peer], PrivateKey, Address, Endpoint и параметры маскировки.

Конфигурация не загружается в интернет и не попадает в публичный репозиторий. При экспорте файла защищайте PrivateKey.

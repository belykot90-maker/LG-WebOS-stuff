# Personal-independent Homebrew catalog on GitHub

The **existing LG-WebOS-stuff GitHub repository** is also our custom repository for the standard LG Homebrew Channel. No new Homebrew Channel application or server is needed.

In Homebrew Channel → Settings → Add repository, enter:

```text
https://raw.githubusercontent.com/belykot90-maker/LG-WebOS-stuff/main/repo.json
```

**Current status:** the catalog is an empty, valid JSON placeholder until universal app IPK files and manifests have been published on GitHub Releases with complete license verification. An empty catalog will not list an installable app yet.

Our **public** distribution will link only to GitHub-hosted releases. Personal VPS endpoints, private server configs, passwords and user keys are never included in this repository.

See [AmneziaWG Universal](apps/amneziawg-universal/README.md) for source code and testing status.
